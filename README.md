# 01-Windows-deployment-
Project Overview

This project simulates a Tier 2 Deskside Support Technician workflow for preparing, deploying, and validating a Windows 11 workstation in Oracle VirtualBox.

Objectives

Assess the virtual machine's baseline configuration.

Document Windows version, system resources, and network settings.

Establish a recovery point before making changes.

Perform deployment and post-deployment validation.

Troubleshoot issues using a structured methodology.

Document findings and handoff notes.

Lab Environment

Host RAM: 32 GB

Virtualization platform: Oracle VirtualBox

Operating system: Windows 11

Installation media: Windows 11 ISO

Project Files

deployment-checklist.md — Pre-deployment checks.

post-deployment-validation.md — Tests performed after deployment.

troubleshooting.md — Problems, evidence, and resolutions.

screenshots/ — Evidence collected during the lab.
